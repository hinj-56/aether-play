# AETHER · 月影遗迹

[打开游戏](https://hinj-56.github.io/aether-play/)

坐着就能玩的 3D 双手魔法防守游戏。左手小幅移动瞄准，右手食指释放星火、V 字释放霜华、三指释放雷霆；能量满后自然张掌 0.8 秒释放星界风暴。也可使用鼠标试玩。

此仓库只包含公开运行所需的构建文件。手势在浏览器本地识别，摄像头画面不上传、不保存。

源码版本：d155ad4a993353e22b5f3362d6188697727a7670

新增六关递进战役、陨石/冰雹/护盾/治疗道具、升级暂停三选一，以及疾行者、夜翼、祭司和裂变魔。

更新手势瞄准：稳定的位移映射、边缘防漂移、相邻目标辅助切换、灵敏度调节与 R 键回正。
